# Normie's loops get their runner scripts (NO-6)

**Ticket:** NO-6, "Normie's loops do not run on the Mini: install its loop lanes"

Normie's tickets were only worked when a session was asked to. This copies in
the six scripts Spirality's own loop jobs run on (from Spirality `d44be1b`):
the installer, the lane runner, the relay runner and three helpers. They live
in `scripts/` because each one finds the product's folder from where it sits,
and they read Normie's settings, so the jobs are named `com.normie.*` and log
to `~/loop-logs/normie-*.log`, beside the other products' and never in them.

The skills and `docs/LOOP_ENGINEERING.md` now say the lanes run, and how to
check on them (`scripts/install_loop_runner.sh --status`) or remove them
(`--uninstall`). Installing them on the Mini is done after this merges.

One gap stays: Normie's copied ticket door predates the command that hands
back a ticket whose build pass died, so such a ticket sits in Building until a
person moves it. The next copy of `loop/` from Spirality brings it.
