# Work log

A plain-English record of what changed on Normie and why, one file per merged
pull request, named `<YYYY-MM-DD>-<branch>.md` (the date in Mountain time).
Each entry is written inside the pull request it describes, so it lands on
`main` with the work, and two pull requests built at once never clash on the
log. `ls -r docs/work-log` lists it newest first. The log is for Dane, not for
the machine; `loop-build` step 5 says how to write an entry.
